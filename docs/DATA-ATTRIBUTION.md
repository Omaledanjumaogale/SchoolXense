# Nigerian residence data

State/FCT and LGA dropdowns are adapted from [Open Admin Data's Nigeria administrative divisions](https://github.com/open-admin-data/nigeria-administrative-divisions), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Downloaded 5 October 2026. Adaptation retains English state and LGA names, sorts them, and omits coordinates and wards. The checked-in dataset contains 37 state/FCT entries and 774 LGAs/area councils. No external API is needed at form runtime.
